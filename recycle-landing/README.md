# RECYCLE demo site

Three pages, all demo (nothing on-chain):

- `/` Overview — the explainer (index.html)
- `/launchpad` Launchpad — launches in every phase, buy with tickets, vault stats, refunds (launchpad.html)
- `/create` Create token — token, Loss Mining, curve, vault rules, review; the new launch appears on the Launchpad (create.html)

Deploy: GitHub repo with these files → share.streamlit.io → main file `streamlit_app.py`, Python 3.12.
Demo launches, buys and the demo wallet are stored in each visitor's browser.
